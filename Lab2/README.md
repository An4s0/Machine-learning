# ARTI308 - Machine Learning Lab 2
## Machine Learning Problem Description

This project focuses on a **classification** problem using an email dataset (`email.csv`) to identify whether an email is **spam** or **ham**.

The dataset includes a **target variable** that indicates the email class, making this a **supervised learning** task. The goal of the model is to learn patterns from the email data and **predict whether a new email is spam or not**.
